# Hotel Digital Menu Card

A website that displays a hotel menu digitally.

## Problem Statement
Customers may find physical menus difficult to read, and hotels need an easy way to display food items, prices, and categories.

## Target Users
- Hotel customers
- Waiters
- Hotel owners

## Features
- Display hotel menu
- Show food categories
- Show food name, image, description, and price
- Search food items
- Add items to cart

## Technologies Used
- HTML
- CSS
- JavaScript
